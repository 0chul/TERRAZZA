# TERRAZZA 운영 및 사업 계획

[사이트 열기](https://0chul.github.io/TERRAZZA/)

진행 체크에서 POS·라마르조꼬·간판·메뉴·일회용품·매뉴얼 준비를 관리합니다. 체크, 담당자, 목표일, 메모는 브라우저에 자동 저장됩니다. 기기 간 이동에는 진행 체크의 JSON 백업/불러오기를 사용하세요. 공동 실시간 동기화는 제공하지 않습니다.

일회용품 발주 수량은 상세 설정의 일 판매량, HOT/ICE 및 포장 비율과 단가에 연결됩니다. 안전재고와 현재 재고를 조정하고 CSV 구매 목록을 내려받을 수 있습니다. 컵·뚜껑 규격과 실제 묶음 수량은 발주 전 확인하세요.

운영 매뉴얼에는 첨부된 v0.9의 9개 장, 검색, 원본 PDF/Word, 날짜별 현장 체크가 있습니다. 매뉴얼의 가격·운영 정책은 초안입니다. 고급 커피는 잔당 10,000~12,000원 구성안이며 판매 비중과 원가 확정 전 재무 예측은 기존 3종을 사용합니다.

자금 집행은 `떼라짜_자금표 및 공사내역_20260824.xls`의 지출 상세 53건을 사용합니다. 사용자 확인에 따라 모든 입금 16,110,000원을 고객 입금으로, 직접구매 4건 389,500원을 고객 직접결제로 분류했습니다. 조영철 카드 4건 269,500원은 개인 선결제로 분리하고 정산 여부는 미확인으로 남겼습니다. 최초 회사 결제는 15,137,450원이며 개인 정산 등록 전 계산 잔액은 972,550원입니다. 현장 총실비 15,796,450원에는 회사·개인·고객이 결제한 실제 비용이 한 번씩 포함됩니다.

결제 주체(회사·개인·고객·미확인)와 비용 종류(공사비·장비·행정운영·부대비·미분류·제외)를 독립적으로 관리합니다. 개인 선결제 정산은 회사 집행액에만 추가하며 현장 총실비를 늘리지 않습니다. 회사 집행 목록은 회사 결제와 등록된 개인 정산을 함께 보여줍니다. 예상 지출과 제외 비용은 현장 총실비에 포함하지 않으며, 회사 자금으로 지출한 제외 비용은 잔액에 반영합니다. 필터·검색·일괄 분류·현재 목록 CSV를 지원합니다. 과거 `#interior` 링크도 자금 집행 페이지로 연결됩니다. 추가 입금일과 원문 `2026-10-0`의 작업일은 미확정입니다.

기존 IndexedDB의 수정되지 않은 기본 내역만 최신 엑셀 값으로 바꿉니다. 사용자 수정 내역과 추가 내역은 보존합니다. 이전 입금 입력 기록은 따로 보관하며 중복 계산을 방지하기 위해 새 합계에서 제외합니다.

## 로컬 실행

Node.js 20 이상에서 `npm ci`, `npm run dev`를 실행합니다. 자금 계산 회귀 검사는 `npm test`, 타입 검사는 `npx tsc --noEmit`, 배포 빌드는 `npm run build`를 사용합니다. `main` 브랜치에 반영되면 GitHub Actions가 자금 계산 검사 후 GitHub Pages에 배포합니다.
